# SimPet 🐾

An arcade-style pet management game currently in active development using **Unreal Engine 5** and **C++**. 

SimPet focuses on resource management and a continuous gameplay loop where the player must balance the needs of multiple pets to achieve the highest possible score.

### 🎮 The Core Gameplay Loop

* **Acquisition:** The player starts by acquiring their first animal for free.
* **Management:** Animals have active needs (such as hunger and cleanliness). The player must actively feed them and clean up after them to keep them happy.
* **Scoring:** As long as the pets are alive and well-maintained, they generate passive points.
* **Progression:** Earned points are used to buy more pets, which increases both the score generation rate and the management difficulty. If an animal's needs are neglected, it dies, breaking the cycle and impacting the score.

### 🛠 Tech Stack

* **Engine:** Unreal Engine 5
* **Language:** C++
